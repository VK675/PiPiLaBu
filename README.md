# PiPiLabu

Aplicativo desktop para aprender ingles com exercicios interativos, treino de pronuncia, progresso local e apoio de IA via Ollama.

## Setup

```bash
npm install
npm start
```

## Build Windows

```bash
npm run build:win
```

## Stack

- Electron 42
- JavaScript
- HTML5
- CSS3
- electron-store
- Ollama
- Web Speech API
- Web Audio API
